# studioneiro.com

Portfolio site of Louis Cluzel, light designer and scenographer.

Static site (HTML, CSS, a little JavaScript), hosted on GitHub Pages.

- `index.html` home and works index
- `work.html?p=slug` project page
- `about.html`, `contact.html`
- `assets/js/projects.js` the list of projects
- `assets/fonts` Doto, Geist and Geist Mono (SIL Open Font License)
